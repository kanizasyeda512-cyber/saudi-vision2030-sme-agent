# Saudi Vision 2030 SME Agent

An AI-powered agent designed to help Small and Medium Enterprises (SMEs) align with Saudi Vision 2030 goals, foster economic growth, and support sustainable development goals (SDGs).

## Features
- Business alignment with Saudi Vision 2030
- SME growth strategy recommendations
- Sustainability and SDG integration

## Files in this Repository
- `app.py`: Main Python script for the agent core logic.
- `docs/`: Documentation and project guides.
